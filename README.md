# er_build_tools

## Tools

- [usb-camera-healthcheck](docs/usb-camera-healthcheck.md) — report USB link speed + verdict for every UVC camera (sysfs only, no root, curl-bash).

- [urdf2usd](docs/urdf2usd.md) — URDF → USD converter.
